# Decentralized Stubborn Observer: platoon simulations

MATLAB code for the numerical example (vehicle platoon) of

> B. Zambotti, V. Andrieu, D. Astolfi, L. Bako, L. Zaccarian,
> **"Decentralized Stubborn Observer Redesign with Exact Outlier Cancellation"**,
> IEEE Control Systems Letters (L-CSS), 2026. Extended version: *link to be added*.

The script compares a **Centralized Stubborn Observer (CSO)**, which uses one global
finite-memory saturation threshold, with the proposed **Decentralized Stubborn
Observer (DSO)**, where every output block has its own finite-memory threshold.
Outliers are injected on the distance sensor of Vehicle 9 (output `y17`, Block 4 of
Table I), and the DSO confines the threshold growth to the attacked block.

## Requirements

- MATLAB (tested on R2024b or later)
- Control System Toolbox (`ss`, `c2d`, `dlqr`, `obsv`)

## How to run

From the repository root, in MATLAB:

```matlab
run_scenarios
```

The script adds `src/` to the path, builds the model and both observers, runs the two
scenarios, prints the RMSE of each observer and opens Fig. 1. It also saves
`scenario2_results.mat` (ignored by git).

## Paper ↔ code

| Paper | Code |
|---|---|
| Platoon model, Section V (N = 15 followers, CTH policy, PF-CACC, ZOH with Ts = 0.05 s) | `src/model_platoon.m` |
| Baseline LQ observer gain L | `run_scenarios.m`, section *System Setup* (`dlqr`) |
| Algorithm 1 (block decomposition), Table I | `src/findAndTransformObserver.m` |
| Finite-memory matrices S, G, R per block; tuning r_i ∈ [0.1, 0.3] scaling with n_i | `src/create_stubborn_matrices_robust.m`, `run_scenarios.m` |
| DSO, Equation (3) | `src/stubborn_finitememory.m` |
| CSO (single block, memory n = 45) | `src/observer_stubborn_finite_memory.m` |
| Scenario a) 1 ≤ T_dwell ≤ n_4: Fig. 1 left column, Table II | `run_scenarios.m`, *SCENARIO 1* |
| Scenario b) T_dwell = n_4 + 1: Fig. 1 right column, Table II | `run_scenarios.m`, *SCENARIO 2* |

The outliers are generated by `src/generate_scenario_disturbance.m`: each one has
random sign and magnitude `magnitude * U[0.5, 1.5]`, i.e. |d| ∈ [5, 15] m. The random
seed is fixed (`rng(1)`), so RMSE values are reproducible from run to run but can
differ slightly from the ones printed in the paper.

## Repository structure

```
run_scenarios.m      main script: reproduces Fig. 1 and Table II
src/
  model_platoon.m                     platoon model (discrete time)
  findAndTransformObserver.m          Algorithm 1: output partition + block-triangular transformation
  create_stubborn_matrices_robust.m   finite-memory matrices S, G, R of the DSO
  stubborn_finitememory.m             one step of the DSO
  observer_stubborn_finite_memory.m   one step of the CSO
  generate_scenario_disturbance.m     outlier sequences
  run_simulation.m                    closed-loop simulation of plant, DSO and CSO
```
